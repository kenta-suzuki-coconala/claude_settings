# retrospective - 振り返り分析とプロジェクト改善 🔍
## 目的
現在のやりとりを分析し、ユーザーの好み・作業パターン・成長ニーズを把握して、より快適で効率的な開発体験を提供するためのプロジェクト設定を最適化します。ソフトウェアエンジニアとしての大成をサポートする情報をCLAUDE.mdに反映します。
## 実行内容
### ステップ1: 会話パターン分析
- ユーザーのコミュニケーションスタイルの特徴を把握
- 好まれるフィードバック形式や情報提示方法を分析
- 技術レベルと学習の方向性を評価
- 作業効率化のパターンを特定
### ステップ2: 技術的嗜好の抽出
- 使用している技術スタックとその理由
- コードスタイルやアーキテクチャの好み
- 開発ツールや手法への関心度
- 学習したい技術領域や課題
### ステップ3: プロジェクト最適化提案
- 現在のCLAUDE.mdの内容を分析
- ユーザーの成長段階に適したガイドライン追加
- 開発効率化のための設定やルール提案
- カスタムコマンドや自動化の提案
### ステップ4: CLAUDE.md更新
- 分析結果に基づくガイドライン追加・修正
- ユーザー固有の開発パターンを考慮した指針
- 成長をサポートする学習リソースや方針
- 効率化のための推奨プラクティス
- セッション要約の記録（必要に応じて）
## パラメータ
- $1: セッションノート（オプション） - 特定の気づきやフォーカスポイントがある場合に指定
## 使用例
```
# 基本的な振り返り実行
> /project:retrospective
# 特定のポイントを強調して分析
> /project:retrospective "型安全性への関心が高い"
# セッション後の振り返りとして実行
> /project:retrospective "推薦システム実装セッション完了"
```
## アウトプット
- **分析レポート**: 会話パターンとユーザー特性の分析結果
- **改善提案**: 開発体験向上のための具体的な提案
- **CLAUDE.md更新**: プロジェクト設定の最適化実行
- **次ステップ提案**: 成長とスキルアップのためのロードマップ
## 活用シーン
- 長時間のコーディングセッション後
- 新しい技術を学習した後
- プロジェクトの節目や完了時  
- 開発効率に課題を感じた時
- 定期的な振り返りとして（週次・月次）

## 実行指示
ユーザーが `/project:retrospective` を実行すると、現在の会話履歴を分析し：
1. **ユーザープロファイル分析**
   - コミュニケーションパターン
   - 技術的関心事と専門レベル
   - 学習スタイルと成長志向
2. **開発体験最適化**
   - 現在のワークフローの課題特定
   - 効率化できるポイントの提案
   - カスタムコマンドや自動化の推奨
3. **CLAUDE.md更新実行**
   - 分析結果を反映した設定追加
   - ユーザー固有のベストプラクティス記録
   - 今後の開発指針の明文化
4. **成長支援提案**
   - 次に学ぶべき技術や概念
   - スキルアップのための具体的アクション
   - 長期的なキャリア成長サポート
このコマンドにより、プロジェクトがユーザーの成長と快適な開発体験を継続的にサポートするリビングドキュメントへと進化します。
