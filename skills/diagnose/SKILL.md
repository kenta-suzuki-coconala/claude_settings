# /diagnose - エラー診断・修復提案

エラーの診断と修復を実行します。

## 使い方

```
/diagnose                        # 直近のエラーを診断
/diagnose "エラーメッセージ"      # 特定のエラーを診断
/diagnose --file path/to/file    # ファイルの問題を診断
/diagnose --log path/to/log      # ログファイルを解析
```

## 処理内容

1. **エラー収集**: ソースからエラー情報を収集
2. **エラー分類**: 種別と重大度を判定
3. **原因分析**: 根本原因を特定
4. **修復提案**: 対応オプションを提示

---

## 実行

{{input}} のエラーを診断してください。

### 必須手順

#### Step 1: エラー情報の収集

入力に応じてエラー情報を収集：

| 入力タイプ | 収集方法 |
|-----------|---------|
| 引数なし | 直近のコマンド出力を確認 |
| エラーメッセージ | 指定されたメッセージを解析 |
| `--file` | ファイルに対して構文・型チェックを実行 |
| `--log` | ログファイルからエラーを抽出 |

#### Step 2: エラー分類

以下の種別に分類：

| 種別 | 説明 | 自動修復 |
|------|------|---------|
| syntax | 構文エラー | 可能 |
| dependency | 依存関係エラー | 可能 |
| network | ネットワークエラー | リトライ |
| permission | 権限エラー | 一部可能 |
| resource | リソースエラー | 提案のみ |
| logic | ロジックエラー | 提案のみ |

重大度を判定：
- `fatal`: 致命的（即時対応必要）
- `recoverable`: 回復可能（自動修復候補）
- `warning`: 警告（任意対応）

```markdown

## Diagnosis

エラー種別: {種別}
重大度: {重大度}

### 元のエラー
```
{エラーメッセージ}
```

### 原因分析
- {原因1}
- {原因2}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
## Recovery Options

### 推奨対応
1. {対応1} (推奨)
2. {対応2}
3. 手動で対応

### 自動修復コマンド（該当する場合）
```bash
{コマンド}
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

#### Step 4: 修復実行（ユーザー確認後）

AskUserQuestion で確認：
- 自動修復を実行するか
- どのオプションを選択するか

確認後、選択された対応を実行。

## オプション

| オプション | 説明 |
|-----------|------|
| `--auto` | 確認なしで自動修復を実行 |
| `--dry-run` | 修復を実行せず、提案のみ表示 |
| `--verbose` | 詳細な診断情報を表示 |
| `--file` | 特定ファイルの問題を診断 |
| `--log` | ログファイルを解析 |
