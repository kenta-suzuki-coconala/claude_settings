# /translate - ココナラ用語・依頼の通訳

ココナラ社員からの依頼を技術的に正確な仕様に変換します。

## 使い方

```
/translate トークルームのクローズ率を分析したい
/translate 見積もりから購入までのCVRを出して
/translate provider_rankって何？
```

## 処理内容

1. **用語の正規化**: ユーザー表現（日常用語）をシステム表現（DB/API用語）に変換
2. **ドメイン情報の提供**: 関連するテーブル名、カラム名を特定
3. **行動ログ分析支援**: 適切なアクション名を特定、SQLクエリパターンを提案

---

{{input}} の内容を通訳してください。

### 必須手順

#### Step 1: リソースの読み込み

```
1. .claude/resources/ubiquitous-dict/aliases.md を読み込む
2. .claude/resources/ubiquitous-dict/index.md で用語のドメインを確認
```

#### Step 2: 用語の抽出と変換

1. 依頼文から用語を抽出
2. aliases.md を参照してシステム表現に変換
3. 不明な用語があれば、ドメイン辞書ファイルを参照

#### Step 3: 行動ログ分析支援（該当する場合）

行動ログ分析の依頼の場合は追加で実行：

```
.claude/resources/coconala/user-action-guide.md を参照
```

- 適切なアクション名を特定
- SQLクエリパターンを提案

### 用語が見つからない場合

1. index.md で類似用語を検索

## 🚀 用語辞書へのコントリビュート（推奨）

### Step 5: 新しい用語マッピングの共有を促す

**翻訳中に新しい用語マッピングを発見した場合**、出力後にユーザーへコントリビュートを提案してください。

#### 提案すべきケース

| ケース | 例 |
|--------|-----|
| 新しいエイリアスの発見 | 「クローズ」→ `talkroom.status = 3` |
| よく使われる略語 | 「GMV」→ `流通総額` |
| 社内独自の用語 | 「プロ認定」→ `provider_rank >= 3` |
| 新機能の用語 | 新しくリリースされた機能名のマッピング |

#### AskUserQuestion での確認

新しい用語マッピングを発見した場合、AskUserQuestion で確認：

```
今回の翻訳で以下の用語マッピングを発見しました：
- {ユーザー表現} → {システム表現}

この用語を aliases.md に追加してPRを作成しますか？

選択肢：
1. PRを作成する（推奨）
2. learned-knowledge.md にメモだけ残す
3. 今回はスキップ
```

ユーザーが「PRを作成する」を選択した場合：
1. `modules/ubiquitous-dict/aliases.md` に用語を追加
2. ブランチ作成からPR作成までを実行

#### aliases.md への追記フォーマット

```markdown
| {ユーザー表現} | {システム表現} | {ドメイン} | {説明} |
```

例：
```markdown
| クローズ率 | close_rate | 取引 | トークルームがクローズされた割合 |
| プロ認定 | provider_rank >= 3 | ユーザー | PRO認定出品者の条件 |
```
