# /persona-interview - ペルソナインタビュー

ペルソナ200人に対してインタビューを実施します。
質問やトピックを投げかけると、関連するペルソナたちが「本人として」反応・意見・感情を語ります。

## 使い方

```bash
/persona-interview ココナラの検索機能を改善するとしたら何が欲しい？
/persona-interview 30代女性に聞きたい: 新しい占い機能について
/persona-interview ビジネス系に聞きたい: 料金体系への感想
/persona-interview 全員に聞きたい: ココナラのNPS
/persona-interview #01, #05, #32 に: チャット機能の使い勝手
```

## 処理内容

1. **入力パース**: 質問とフィルタ条件（セグメント・人数・特定ペルソナ）を分離
2. **インデックス読み込み**: ペルソナインデックスから対象候補を特定
3. **ペルソナ選定**: 質問トピックに関連するペルソナを選定し、ユーザーに確認
4. **並列インタビュー実施**: Task agent を人数分並列起動し、各ペルソナが独立にキャラクターとして回答
5. **クロス分析**: 共通点・相違点・属性別傾向を分析
6. **レポート出力**: Markdownファイルとして保存

### 必須手順

---

#### Step 0: 入力パース

ユーザー入力 `{{input}}` から、**質問本文**と**フィルタ条件**を分離します。

**パースルール**（優先度順）:

| 検出パターン | モード | 動作 |
|-------------|--------|------|
| `全員` `全ペルソナ` `200人` を含む | 全員モード | 200人全員を対象（簡易回答） |
| `#数字` や人物名（例: `桐山瑞希`）を含む | 特定指定モード | 指定されたペルソナのみ |
| `N人に` を含む | 人数指定モード | N人を自動選定 |
| `20代女性` `30代男性` 等の属性を含む | セグメントフィルタ | 該当属性のペルソナに絞り込み |
| `ビジネス系` `クリエイティブ系` `悩み系` `ライフイベント系` `ニッチ系` を含む | バッチフィルタ | 該当バッチのペルソナに絞り込み |
| 上記なし | 自動選定（デフォルト） | 質問トピックに基づき5〜8人を自動選定 |

フィルタ部分（`〜に聞きたい:` や `〜に:` 等）を除いた残りが**質問本文**です。

**パース結果を表示**:
```
入力パース結果:
- モード: {自動選定 / セグメントフィルタ / 全員 / 特定指定}
- フィルタ: {該当する場合のフィルタ条件}
- 質問本文: {質問内容}
```

#### Step 1: ペルソナインデックス読み込み

Read ツールで以下のファイルを読み込みます:

```
.claude/resources/persona/persona-index.md
```

※ 上記はプロジェクトルートからの相対パスです。Read ツールに渡す際は絶対パスに変換してください。

#### Step 2: ペルソナ選定

インデックスの情報を使って、質問に最も関連するペルソナを選定します。

**自動選定モード（デフォルト）の選定ロジック**:

1. 質問本文からトピックキーワードを抽出
2. インデックスの「トピック別索引」で第一候補群を特定
3. インデックスの「検索用キーワード」列で各ペルソナとの関連度を評価
4. **多様性の確保**（以下のバランスを考慮）:
   - 異なるバッチから最低2バッチ以上
   - 性別が偏りすぎない（可能な範囲で複数の性別を含める）
   - 年代が偏りすぎない（可能な範囲で2年代以上）
5. **5〜8人**を選定

**セグメントフィルタモード**:
1. 属性別索引から該当ペルソナ番号を取得
2. その中から質問に最も関連する5〜8人を選定
3. 該当セグメントが5人以下の場合は全員を対象

**バッチフィルタモード**:
1. バッチ別索引から該当ペルソナ番号を取得
2. その中から質問に最も関連する5〜8人を選定

**特定指定モード**:
1. 指定された番号・名前のペルソナをそのまま対象とする

**全員モード**:
1. 200人全員を対象とする（Step 3での実施方法が異なる）

**選定結果の表示（必須）**:

選定後、以下をユーザーに表示し、AskUserQuestion で確認します。

```
【選定されたペルソナ（{N}人）】

| # | 名前 | 性別/年代 | セグメント | 選定理由 |
|---|------|----------|-----------|---------|
| XX | ○○ ○○ | F/35歳 | ○○ | {質問との関連性を1文で} |
| ... | ... | ... | ... | ... |

このメンバーでインタビューを実施しますか？
```

選択肢:
- 「このまま実施」（推奨）
- 「ペルソナを変更したい」

ユーザーが変更を希望した場合は、追加・除外・入替の指示に従って選定を修正します。

---

#### Step 3: 並列インタビュー実施

**通常モード（8人以下）**:

選定された各ペルソナに対し、**Task tool を同一メッセージ内で全員分呼び出し**、並列にインタビューを実施します。
各 agent が独立にペルソナファイルを読み込み、回答を生成するため、メインコンテキストに詳細データを読み込む必要はありません。

**重要**: 一度に起動する agent は**最大8人**です。
8人を超える場合はユーザーに以下を提案:
- 8人に絞り込む
- 2回に分けて実施する
- 全員モード（簡易回答）に切り替える

**Task tool の呼び出し方**:

選定された各ペルソナについて、以下のパラメータで Task tool を呼び出します。
**必ず1つのメッセージ内で全員分の Task tool を同時に呼び出してください**（並列実行のため）。

```
Task tool パラメータ:
- description: "ペルソナ#{番号}インタビュー"
- subagent_type: "general-purpose"
- model: "haiku"
- prompt: （以下のテンプレートを使用）
```

**各 agent へのプロンプトテンプレート**:

```
あなたはペルソナインタビューの実施エージェントです。
以下の手順で、担当ペルソナとして質問に回答してください。

## 手順

1. Read ツールで以下のファイルを読み込んでください:
   {ペルソナファイルの絶対パス}
   （例: .claude/resources/persona/personas/003_20代女性_推し活クリエイター.md をプロジェクトルートの絶対パスと結合）

2. ファイルの内容を理解した上で、以下の質問に「本人として」回答を生成してください。

## 質問

{質問本文}

## キャラクター表現のルール

1. **一人称**: ペルソナの人物像に合わせる
   - 若い女性: 「私」「あたし」
   - 中年男性: 「俺」「私」「僕」
   - ビジネスパーソン: 「私」
   - 年配の方: 「わたし」「あたくし」
   - ノンバイナリー: 「自分」「僕」等、ペルソナの設定に従う

2. **口調**: 年齢・性格・職業・居住地に合った話し方
   - カジュアル/フォーマル
   - 方言がある場合は適度に反映
   - 職業用語を自然に混ぜる

3. **具体性**: ペルソナの生活状況、職業、家族構成を踏まえた具体的なエピソードを織り交ぜる
   - 「うちの工場では〜」「夜勤明けに〜」「子どもの送り迎えの合間に〜」等

4. **感情表現**: 単なる意見ではなく、感情を含める
   - 嬉しい、不安、イライラ、期待、戸惑い、共感、無関心 等

5. **矛盾も許容**: ペルソナの性格上ありえる矛盾や迷いも表現

6. **長さ**: 200〜400文字

## 出力フォーマット（厳守）

以下のMarkdown形式で出力してください。これ以外のテキストは出力しないでください。

### #{番号} {名前}（{年齢}・{性別} / {セグメント}）

> 「{ペルソナのキャラクターとしての回答。かぎ括弧で囲み、話し言葉で。
> 具体的なエピソードや感情を織り交ぜ、200-400文字で。}」

**背景**: {この回答に至る背景を客観的に1-2文で補足}
**感情**: {回答時の主な感情を1-2語で}（例: 期待と不安, 強い共感, 戸惑い）
**ココナラ利用への影響**: {この質問のトピックがココナラ利用に与える影響を1文で}
```

テンプレート中の `{番号}`, `{ペルソナファイルの絶対パス}`, `{質問本文}` は、選定結果に基づいて実際の値に置換してください。
ファイルパスはインデックスの「ファイル名」列から取得し、`.claude/resources/persona/personas/{ファイル名}` の形式（プロジェクトルートからの相対パス）にします。Read ツールに渡す際は絶対パスに変換してください。

**全 agent の結果を受け取ったら**、各 agent の出力をペルソナ番号順に並べてユーザーに表示します。

---

**全員モード**:

全員モードでは agent を使用しません。
インデックスの情報（名前、性別/年代、セグメント、主要カテゴリ、検索用キーワード）のみで簡易回答を生成します。

ユーザーに以下を表示:
```
全員モード: インデックス情報に基づく簡易回答で実施します。

```

```markdown
| # | ペルソナ | 反応 | 感情 |
|---|---------|------|------|

| 02 | 藤田 美穂（F40代） | {50-100文字の簡潔な反応} | {感情キーワード} |
| ... | ... | ... | ... |
```
